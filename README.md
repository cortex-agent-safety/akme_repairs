# Akme Repairs LLC

A responsive, accessible one-page website for Akme Repairs LLC, built as a dependency-free static site for GitHub Pages.

## Preview locally

Open `index.html` in a browser, or serve the folder with any static web server.

## Publish with GitHub Pages

In the repository settings, open **Pages**, choose **Deploy from a branch**, then select the main branch and `/ (root)` folder.

## Contact form

The estimate form opens the visitor's email application. Update `CONTACT_EMAIL` in `script.js` when the company's preferred inbox is available.
