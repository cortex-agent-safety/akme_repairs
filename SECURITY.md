# Security Policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue.

Report them privately to `contact@akmerepairs.com` with:

- the affected page or file;
- steps to reproduce the issue;
- the potential impact; and
- any suggested remediation.

Do not include secrets, customer information, or other sensitive data beyond what is necessary to explain the issue. Akme Repairs LLC will acknowledge a report as soon as practical and coordinate disclosure after a fix is available.

## Supported version

Security fixes apply to the version currently published from the `main` branch.
